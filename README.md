# ClipForge — تطبيق مونتاج فيديو للموبايل

تطبيق React Native (Expo) + TypeScript لمونتاج الفيديو: خط زمني بطبقات متعددة، قص/تقسيم/سرعة/عكس/تكرار، نصوص عربية وإنجليزية،
ترجمة تلقائية (Whisper) تعمل أوفلاين، وتصدير حتى 4K@60 بدون علامة مائية. **يعمل بدون سيرفر وبدون إنترنت** (عدا تنزيل نموذج الترجمة مرة واحدة).

## أسهل طريقة للحصول على التطبيق (بدون أي حساب أو إعداد)

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد (انظر الخطوات أدناه).
2. افتح تبويب **Actions** ← workflow باسم **Build APK** ← انتظر ~15–25 دقيقة.
3. من صفحة التشغيل نزّل الملف **ClipForge-apk** (داخله ملف `.apk`) وثبّته على هاتف Android.
   (يجب السماح بالتثبيت من مصدر غير معروف.)
4. لنشر نسخة على صفحة **Releases**: أنشئ وسمًا مثل `v1.0.0` (الأوامر أدناه) وسيُرفق الـ APK تلقائيًا.

## Enable export — تفعيل التصدير والترجمة (خطوة مطلوبة)

التصدير والترجمة التلقائية يعتمدان على FFmpeg. مكتبة `ffmpeg-kit-react-native` الرسمية **أُوقفت وأُزيلت ملفاتها الجاهزة**، لذلك لم أضمّنها
افتراضيًا (حتى يبقى البناء ناجحًا). بدونها كل شيء يعمل (المعاينة، التحرير، الحفظ) وعند الضغط على تصدير يظهر تنبيه يشرح السبب.

الخيارات (اختر واحدًا):

1. **FFmpegKitNext** (امتداد رسمي من نفس المطوّر): https://github.com/arthenica/ffmpeg-kit-next — مصدر فقط، تبنيه بنفسك وينتج ملف `.aar`.
2. أي ملف `.aar` لـ FFmpegKit تثق به. **انتبه:** ملفات ثنائية من مصادر غير معروفة قد تكون خطرة، ورخصة نسخة GPL تفرض شروطًا على تطبيقك.

بعد الحصول على الملف:

```bash
npm i ffmpeg-kit-react-native@6.0.2
# ضع الملف هنا (الاسم مهم):
cp /path/to/your.aar vendor/ffmpeg-kit.aar
git add . && git commit -m "enable ffmpeg" && git push
```

الـ plugin في `plugins/withFfmpegAar.js` يربط الملف تلقائيًا وقت البناء (**لم أستطع اختباره**؛ لو فشل البناء أرسل لي سجل الخطأ).
الكود نفسه يعمل مع أي مكتبة تقدّم نفس واجهة FFmpegKit (`src/engine/ffmpeg.ts`).

## كيف يعمل التصدير

`src/export/plan.ts` يحوّل المشروع إلى أمر FFmpeg واحد (filter_complex): المسار الرئيسي ← طبقات Overlay ← النصوص ← الصوت.
النصوص تُرسم كصور PNG شفافة بنفس مكوّن المعاينة (فيظهر العربي بالتشكيل الصحيح)، ثم تُركَّب فوق الفيديو.
الترميز بالعتاد (`mediacodec`) أولًا ثم يعيد المحاولة تلقائيًا بالترميز البرمجي لو فشل.
هذا المخطط **جرّبته فعليًا على FFmpeg 6.1** (تقسيم، سرعة، عكس، صور، GIF، تراكب، نص متحرك، صوت) والنتائج صحيحة.

## قيود معروفة

- العكس يظهر إطارًا بإطار في المعاينة (التصدير سلس). عكس مقاطع طويلة جدًا يستهلك ذاكرة أثناء التصدير؛ الأفضل أقل من ~30 ثانية.
- مزج أكثر من مسار صوتي يخفّض الصوت قليلًا (FFmpeg 6 لا يملك `amix normalize`).
- لا توجد صور مصغرة (thumbnails) داخل مقاطع الخط الزمني.
- الخط الزمني يبقى من اليسار لليمين حتى في الواجهة العربية (هذا مقصود).
- الخطوط مضمّنة في التطبيق عبر حزم `@expo-google-fonts/*`. لإضافة خط: ثبّت حزمته وأضف سطرًا في `src/fonts/fonts.ts`.
- أُزيلت ميزات: السيرفر (Fastify)، Whisper API أونلاين، تسجيل الدخول — لأنها غير لازمة للتطبيق الأوفلاين.
- الكود لم يُجرَّب على جهاز حقيقي بعد (كتبتُه في بيئة بلا Android). أرسل لي أي خطأ يظهر وسأصلحه.

## التطوير محليًا (اختياري)

```bash
npm install
npx expo prebuild --clean       # يولّد مجلد android/ (مطلوب لأن Skia/MMKV/whisper.rn مكتبات native)
npx expo run:android            # يبني ويشغّل على جهاز/محاكي (يحتاج Android Studio + JDK 17)
npm test                        # اختبارات المنطق
npm run typecheck
```
